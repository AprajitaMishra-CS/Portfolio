# Personal Portfolio

A modern, responsive, and interactive personal portfolio built to showcase my projects, technical skills,
and development journey.

## Live Demo

View Portfolio - https://aprajita-portfolio.onrender.com

## Features

- Modern and premium dark-themed UI
- Responsive design for all screen sizes
- Smooth animations and interactive elements
- Projects showcase section
- Detailed project case studies
- Clean navigation and user-friendly experience
- Minimal and professional design

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Motion
- Lucide React
- React Icons

## Installation & Setup

Clone the repository:

```bash
git clone 
http://github.com/AprajitaMishra-CS/Portfolio
```

Navigate to the project folder:
```bash
cd portfolio
```

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
